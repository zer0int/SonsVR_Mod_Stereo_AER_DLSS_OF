# Sons of the Forest VR — community fork

Unofficial SteamVR/OpenVR support for *Sons of the Forest*, based on [iPowerTech/SonsVR_Mod](https://github.com/iPowerTech/SonsVR_Mod) (original mod by Antonio Mauriello). This repository snapshot contains the tested **V163H gameplay/rendering baseline** with the **V168G settings-only addition**. The legacy SteamVR gesture input option is present but **currently unsupported; leave it OFF**. Native Xbox/gamepad control is the recommended input mode.

This is a **source repository**, not a precompiled installer. It builds `SonsVR_Mod.dll` and `SonsVR_NvOF_V90.dll` for Windows; the game and generated IL2CPP assemblies are not distributed.

## Highlights

- Stereo VR rendering, with selectable normal two-eye (`2E`) and experimental alternate-eye (`AER`) reconstruction paths. The latter includes depth-aware reprojection and guarded hole handling.
- Gamepad-first input with native 3D gaze selection for the cooking menu, backpack and both held books (including blueprint tabs and subtabs).
- World-space HUD, minimap and menus; the HUD sheet is raised **7 cm** relative to the user's head for practical visibility. The HUD deliberately retains ordinary depth occlusion.
- Title/menu re-entry, helicopter cutscene camera handoffs, and New Game/Load Game coverage tuned for VR; construction blueprint previews remain visible.
- Runtime settings panel: **View+Menu** or **Ctrl+Alt+F10** (function key configurable), with recenter, render-mode and optical-flow options, overlay scaling, and self-migrating `SonsVR_Settings.ini`. DLSS is controlled through the game's native **Options → Graphics** menu.
- Native NVIDIA optical-flow bridge, and optional profiling/tracing components retained for future maintenance.

See [CHANGELOG.md](CHANGELOG.md) for the concise history and source entry points.

## Building (Windows)

Prerequisites:

1. An installed copy of *Sons of the Forest* with MelonLoader, its generated `MelonLoader/Il2CppAssemblies`, and the upstream SteamVR/OpenVR runtime requirements already installed.
2. **.NET 6 SDK**, **Visual Studio C++ x64 build tools** (including the Windows SDK), and **Unity Editor 2022.2.16f1**.
3. Python is **not** required for building. The build uses the included Unity project and NVIDIA Optical Flow SDK sources/headers.

Build from the repository root:

```bat
BUILD_RELEASE.bat "D:\SteamLibrary\steamapps\common\Sons Of The Forest"
```

If Unity is installed elsewhere, set `UNITY_EXE` to the executable path before running. You can also set `SONS_GAME_DIR` instead of passing an argument. The build script assembles the native bridge, compiles the GPU shader AssetBundle and embeds it in the managed mod DLL; it **does not automatically install into the game**.

On success, copy **both** DLLs from `OUTPUT/` into the game's `Mods/` directory, replacing the corresponding earlier mod DLLs while the game is completely closed. Retain the upstream installation's VR input/bindings support. Game-specific IL2CPP assemblies are referenced locally from `SONS_GAME_DIR`, not bundled in the repository.

The original C# project can also be built with MSBuild property `SonsGameDir`, provided that `mod/Resources/sonsvr_depththingy` has first been generated by the Unity shader build.

## Controls and configuration

Use an **Xbox-compatible controller** for gameplay. Open the settings panel with **View + Menu** (hold briefly), or **Ctrl + Alt + F10**; navigate with D-pad/arrows. The settings are saved to `SonsVR_Settings.ini` alongside the installed mod DLL and are migrated when fields change. The legacy VR gestures toggle is exposed for compatibility but is **not supported in this tested release**; keep `LegacyVrGesturesEnabled=False`.

Changes to VR render scale and legacy input mode require a restart. Native game graphics settings, including DLSS, are configured in the normal game's options UI.

## Known limitations

- World-space HUD elements are subject to ordinary 3D occlusion (for example, a large held axe). This is intentional: the experimental depth-bypass UI shader branch was abandoned after rendering regressions. Do **not** integrate V164–V166 shader experiments into this source.
- SteamVR gesture input is experimental/unsupported in this fork; Xbox/gamepad is the tested default.
- Some native action-prompt icons may not appear reliably even when the actual interaction works.
- Game updates, alternative input devices, and hardware configurations may require further compatibility testing.
